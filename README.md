# Professional HTML Email Developer Portfolio

Welcome! I am a responsive email developer specializing in building clean, pixel-perfect, and high-converting email templates using semantic HTML and inline CSS. 

Unlike standard web pages, HTML emails require strict, specialized coding practices to ensure they look identical across all major inbox clients (Gmail, Outlook, Apple Mail, and Yahoo) and all mobile screen sizes.

---

## 🛠️ Technical Specialties
* **Table-Based Layouts (`<table>`):** Coded defensively to survive rigid rendering engines like Microsoft Outlook.
* **Inline CSS Styling:** Applied directly to elements to prevent styling blocks from being stripped by Gmail.
* **Fluid & Responsive Design:** Utilizing fluid percentages, hybrid formatting, and media queries for a seamless mobile smartphone experience.
* **MSO Vector-Based Buttons:** Implementing Bulletproof VML buttons so calls-to-action render properly everywhere.
